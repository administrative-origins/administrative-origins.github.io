IndividualIn progress

This phase turns the yearly Official Registers of the United States (1817–1959) into a single standardized file with one row per person-year. It harmonizes column headers across eras and cleans the fields that the registers abbreviate inconsistently: position, birth state, appointing state, employing state and congressional district. It also converts stated pay into a yearly figure. Abbreviations are resolved through crosswalks, which are filled from earlier hand codings, then by Claude, and checked against human coders. The scripts run in order, and each step reads the previous step’s output.

Download final output (CSV) Download full folder

The final output is all_registers_1817_1959_clean.csv (about 800 MB). The full folder (about 13 GB) holds the code, the yearly register inputs and PDFs, the crosswalks, the reliability samples, and all output tables and figures.

Steps

  1. Bind all registers Reads the 73 yearly Official Register spreadsheets (1817–1959), standardizes their column headers across the three header eras, and binds them into one file. Exact repeats, and rows that differ only in where the person worked, are collapsed into one row, with n_collapsed recording how many original rows each stands for. Output: all_registers_1817_1959.csv.
  2. Generate empty crosswalks The registers abbreviate and spell the same thing in many ways, so the raw position, cong_district and the three state fields (state_born, state_appointed, state_employed) are turned into crosswalks: one row per unique raw string, most frequent first, with an empty _clean column. Positions are only abbreviated in 1907–1921, so that crosswalk has one row per term and year; the three state fields share one crosswalk.
  3. Fill crosswalks from hand codings Many of the abbreviated and otherwise unstandardized entries were decoded by Kevin Angell. His entries, which cover all of the most common position titles and locations, are added to the empty crosswalks.
  4. Test Claude crosswalk generation Before using Claude to fill the remaining entries, we test it against human coders. The script draws random samples of still-unfilled entries (50 states, 50 districts, 150 positions). Then, Jon Rogowski and Lucas Cain filled these samples, and their results are compared to Claude (Sonnet 5.5, medium). The script reads back each coder’s filled sample, and computes inter-coder agreement (pairwise agreement, Cohen’s κ, and Krippendorff’s α). Disagreements are hand-marked as substantive or trivial, and agreement is reported both ways. The high agreement rates, and plausible entries by the LLM in cases of disagreement, justify step 5.
  5. Fill crosswalks (Claude) The prompt used to have Claude fill the remaining blank crosswalk entries: districts and states first, then positions in batches. Each entry is checked individually against the printed abbreviation lists in Input/c. Abbreviations, and uncertain entries are left blank for human review. Existing answers are never overwritten.
  6. Apply crosswalks and additional cleaning Applies the filled crosswalks to the master register to produce standardized state, district and position fields. Also corrects the shifted “D C D C D C” entries in the compact registers, blanks the 1881–1891 district column (which holds field-service headings, not congressional districts), and converts pay strings into a comparable yearly figure. Output: all_registers_1817_1959_clean.csv, which completes Phase 1.
  7. Descriptive Tabulates and plots coverage by year for each cleaned field, birthplace patterns, compensation in nominal and real dollars (using the Officer–Williamson price and wage series), and employment geography. Tables and figures are written to Output/Tables and Output/Figures.

Replication code

All scripts are in code/individual/. The R scripts pin package versions with groundhog (as of 2026-09-25) and read from and write to the Box folder Data Generation/1. Individual, so update the base_dir path at the top of each script to your local copy of the downloaded folder.

Inter-coder reliability
